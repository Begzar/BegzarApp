## 📖 درباره بگذر

**بگذر** یک سرویس VPN است که با تمرکز بر سادگی، امنیت و پایداری طراحی شده است. نسخه‌های **اندروید** و **ویندوز** با هر انتشار گیت‌هاب منتشر می‌شوند؛ نسخه اندروید همچنین در [Google Play](https://play.google.com/store/apps/details?id=cloud.begzar.begzar) در دسترس است.

هدف بگذر فراهم کردن دسترسی مطمئن به اینترنت بدون پیچیدگی‌های فنی است؛ اتصال سریع، رابط کاربری شفاف و به‌روزرسانی خودکار سرورها از ویژگی‌های اصلی این سرویس به‌شمار می‌روند.

## 🧑‍💻 ساخت از سورس

به [Flutter](https://docs.flutter.dev/get-started/install) نسخه 3.44.2 (stable) نیاز دارید.

```bash
git clone https://github.com/Begzar/BegzarApp.git
cd BegzarApp
flutter pub get
flutter run
```

- 🔌 **بدون هسته:** برنامه باز می‌شود اما نمی‌تواند متصل شود و پیام می‌دهد که هسته‌ی بگذر در این نسخه وجود ندارد.
- 🔕 **بدون Firebase:** آنالیتیکس، نوتیفیکیشن و پیام‌های درون‌برنامه‌ای غیرفعال‌اند. برای استفاده از پروژه‌ی خودتان `flutterfire configure` را اجرا کنید.
- ✅ دستورهای `flutter analyze` و `flutter test` روی یک کلون تازه بدون خطا اجرا می‌شوند.
- 🛡️ نسخه‌های رسمی توسط بگذر امضا می‌شوند و فقط از [Releases](https://github.com/Begzar/BegzarApp/releases/latest) و Google Play منتشر می‌شوند.
